# persona-ab-factory（日本語要約）

指示ファイル（CLAUDE.md 等）を「規則として書く」か「人格として書く」かで、エージェントの拒否の仕方・圧をかけられた時の正直さ・書いた本人に「解除する」と言われた時に線が保つか、がどう変わるかを、夜間の A/B で測る常設の実験装置。これはその**最小公開版**＝設計書・台帳の型（1ジョブが通る8工程）・最初の実験で使った汎用の指示ファイル2本とプローブ。

実例（won't vs cannot・Round 1 の生答案＋Round 1〜3 の write-up・2〜3 は報告のみで再現材料なし）は既に姉妹 repo [low-pressure-claude-md](https://github.com/TJ11000/low-pressure-claude-md) の experiments/ で公開済みなんで、ここでは再掲せずリンクだけ。この repo が足すのは「その実験を回した装置の設計」と「ジョブの手順」。

**入っていないもの**: 稼働中の台帳・ジョブ本体・variant（id 001〜054（2026-09-11 時点）は起票順であって時系列やない・複数ジョブを1晩に束ねる夜もある）／現行の judge プロンプト／runner。ただし「原理で伏せとる」やなく範囲の話＝個別ジョブの write-up と、2件は材料・rubric・driver まで姉妹 repo の experiments/ に公開済み。伏せとるのは稼働中の台帳と現行の計器（公開したら試験対策される）だけ。ベンチマークもない。
